# Herbeloved

Herbeloved is an imitation jewellery storefront by Barai Enterprises.

## Brand
- Tagline: Made to Adore
- Theme: Maroon and gold
- Domain: herbeloved.com

## Website files
- `index.html` — storefront homepage
- `styles.css` — responsive styling
- `script.js` — shopping bag interactions
- `policies.html` — shipping, returns, privacy, terms and care
- `CNAME` — custom domain configuration for GitHub Pages

## Publishing
This repository is prepared for static hosting. GitHub Pages still needs to be enabled from the repository settings if it is not already enabled.

## Important before taking live orders
Replace placeholder contact details, verify product prices and stock, add real product photographs, finalize shipping/return terms, and connect a secure payment checkout provider. Never store payment card or bank credentials directly in these files.
